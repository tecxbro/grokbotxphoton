# WT-04 media architecture

## Execution and authorization
`createFeatureModule(options)` returns the frozen `FeatureModule` with owner wt-04 and exactly attachment.send, attachment.fetch, voice.send and contact.send. The named handlers delegate to `mapMediaOperation`, which parses bounded action JSON and checks context ID, permission and the active claim. No new handler reads private outbox, attempts, children or checkpoints. Existing `createMediaModule` and `SafeMediaStager` remain compatibility-only; do not register them as the public module.

`MediaProviderContext` is injected from the existing connection owner. Its space/message resolvers and `getAttachment` belong to Spectrum 12.8.0. `mappedMediaReference` reads only the shared references domain table and checks project/provider/account/line/chat, principal, task and generation. Each asynchronous resolution is followed by an active-claim check. Before sending, the SDK space must match the logical-to-native mapping, binding conversation and serving phone. The mapping is rechecked at dispatch.

`sendAttachment`, `sendVoiceNote` and `sendContact` build bounded content before calling `executeChild` with index 0 and a stable parsed-action digest/key. The shared executor owns request scoping, durable child records, dispatch intent and recovery. No provider call happens in a database transaction. Empty SDK returns, errors after dispatch or failures recording a returned message become unknown-outcome/reconcile-first. The lane never retries them as a different content type. SDK acceptance does not establish delivery/read. Child OperationResult requestId uses the parent action idempotencyKey because the public service does not expose a requestId; runtime owns canonical parent result association.

## Safe sources and consumer port
`stageMediaResource(stager, source)` is trusted-host-only. Sources are approved absolute files, allowlisted HTTPS URLs or authorized native attachment references. Wire JSON accepts only the frozen staged descriptor or scoped attachment reference. No inline binary JSON, raw path, URL, SDK instance or alternate downloader is accepted from action arguments.

`GuardedMediaStager` implements the unchanged `MediaStager.resolve(media, context)` port. Bind a scoped instance to `ExecutionServices.media`. Avatars, backgrounds and other feature consumers use that frozen port, without importing this lane's private implementation. The host calls `createMediaResourceCapacity()` once and shares it across scoped stagers. `resolveMediaResource(media, services)` rechecks claim/cancellation and retains the shared record before reading. The returned runtime object includes bytes/MIME and optional bounded metadata; the wire descriptor remains unchanged.

## File lifecycle and metadata
Imports stream into exclusive private UUID `.part` files with 64 KiB write slices. After bounded consumption, validate MIME signature and real size, fsync, hash bytes, write and fsync immutable metadata, rename the data file and fsync the directory. Only then insert a scoped stagedMedia row. The final relative path is `<uuid>.<metadata-sha256>.bin`; its companion JSON hash is bound by that shared row. Metadata files are immutable resource attributes, not a private execution journal or database. Row SHA-256 binds the binary. No migrations or shared schema changes are needed.

Metadata preserves logical source/message/scope, provider-native attachment/message/conversation IDs, original name, MIME, actual size and known duration. Bounded native retrieval metadata retains guid, fileName, mimeType, totalBytes, transferState, uti, hidden/sticker flags, companionKind and originalGuid. Native retrieval checks parent membership, phone, readiness and size/MIME agreement before streaming. Reply/group traversal recovers known voice duration. Spectrum's public stream downloads the primary attachment; companion metadata is retained, but companion bytes/HEIF conversion are not added. Upload names may use a MIME-compatible extension while original names remain in metadata.

## Retention and recovery
`retainResource(unit, descriptor, context)` authorizes the existing domain row and idempotently sets expiresAt to Number.MAX_SAFE_INTEGER. Time alone cannot release queued, retrying, accepted-but-unresolved or unknown work. Retains occur before asynchronous reads and must also be wired atomically during runtime action admission for every consumer.

`releaseResource(unit, descriptor, context, expiresAt, noConsumers)` requires a trusted synchronous no-consumer proof in the same transaction. `cleanExpiredResources` checks expiry and the proof again, then commits a tombstone before unlinking. Tombstone retries are idempotent. `GuardedMediaStager.clean` also refuses cleanup during its active reads. The runtime proof must fence admission and cover all processes/readers and pending/retrying/unknown execution. No callback means no release or collection. This proof is not implementable from frozen UnitOfWork alone; CR-04-1 remains an integration requirement, not a claimed production guarantee.

Exceptions unwind partial files and unpublished metadata/data. SIGKILL/power-loss between filesystem publication and database insertion can leave unreferenced files. Never delete these during concurrent activity: offline quiescent orphan cleanup belongs to the host after authoritative reconciliation. Directory-entry limits bound accumulation and fail closed until maintenance. No live cleanup scheduler is installed.

## Filesystem threat boundary
`openApprovedFile` rejects relative/traversal/NUL paths and symlinks in the untrusted suffix, including ancestors; configured root aliases are canonicalized. It rejects nonregular or multiply linked files, opens O_NOFOLLOW/O_NONBLOCK, compares dev/inode/link count and rechecks canonical identity. Reads retain that opened descriptor. Source changes after opening cannot redirect the handle; content hashing describes the bytes actually staged.

Configured roots and staging directory ancestors are controlled by the runtime OS identity. Portable Node APIs do not provide an openat2-style directory capability. Malicious same-UID ancestry swaps, in-place writers and processes with runtime credentials are outside this boundary; this is not a sandbox against them. UUID/hash paths never incorporate incoming names or URLs. The staging directory must be owner-private and files use 0600.

## Network and resource bounds
`createGuardedFetcher` validates HTTPS scheme, credentials, exact allowlisted hostname, port, URL length and each redirect. All DNS answers must be public; private, loopback, link-local/metadata, multicast, mapped/transition and reserved addresses are rejected. The HTTPS request pins one approved answer, retains TLS hostname validation, disables pooled/proxy sockets and checks the connected peer. Redirects rerun host/DNS policy; late responses after cancellation are closed. No one-time URL validation followed by an SDK URL download occurs.

`fetchApprovedResource` additionally bounds actual streamed bytes, total deadline and four outstanding bodies, including unread bodies. Host-only DNS/request injection supports controlled fixtures; production uses the pinned HTTPS implementation. Guarded staging uses the same hop validation plus bounded streaming and its shared capacity. Content-Length never substitutes for byte accounting. Defaults: 25 MiB/resource, 30 seconds, four active staging operations, 768 directory entries. Host may lower byte/time/entry bounds; hard limits are 25 MiB, 120 seconds and 10000 entries. Admission scans stop at the entry bound. Concurrent operations may transiently overshoot the entry cap by at most the bounded in-flight operation count times their temporary files; the single host must share capacity. Returned F0 bytes necessarily materialize a bounded Buffer. Signature checks do not decode or prove media playability.

## Voice and contacts
Voice sends an existing audio resource. Host policy explicitly selects native voice or ordinary audio-attachment fallback; the latter is reported as fallback and is not described as native. No synthesis, transcription or calling is implemented. Provider-side audio conversion, actual waveform rendering and device playback are untested.

Contact sends use universal contact content, separate from native account.shareContact. The frozen input supports a display name, E.164 phone list and email list. `compileContact` rejects control characters; schema validation bounds names/lists and validates phone/email fields. `importVCard` bounds bytes/UTF-8 and rejects extra fields; `exportVCard` uses the real public serializer. Supported fields round-trip including punctuation. Richer official contact fields require a future shared-contract change and are not silently added to wire JSON.
