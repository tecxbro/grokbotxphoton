# WT-06 app cards
Implement app.send, app.sendCustomized and app.update using Spectrum 12.8.0 cloud iMessage and f0-services-2. The host injects its existing space/message resolvers, configured templates, request identity and admission-time expected revision. No credentials or resources are invented.

Static URL-backed app cards, customized extension cards, installed-extension live rendering and authenticated backend callbacks have separate availability. Rich links belong to the text lane and cannot substitute for a card update. Runtime integration, activation and device behavior remain unverified.
