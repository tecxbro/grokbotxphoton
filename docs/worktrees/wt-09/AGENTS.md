# WT-09 lane rules

WT-09 owns only the independent test and documentation paths named in the user assignment. Production source, shared contracts, migrations, dependencies, registries, host wiring, fixtures, verification scripts, root documentation, and other lanes are read-only.

Tests preserve the product contract: missing implementation is a failing product result, never an unsupported or skipped success. Evidence is labeled separately as fixture/unit, pinned SDK contract, real local integration, provider acceptance, delivered/read observation, interaction, or device rendering. No live action runs without an explicit, expiring approval for the exact candidate, account, line, conversation, and action.

The four pre-existing relocation edits outside this lane remain unstaged and untouched. WT-09 commits must stage only task-owned paths and must not merge feature branches.
